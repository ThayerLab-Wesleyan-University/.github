# Thayer Laboratory

The Thayer Laboratory at Wesleyan University applies computational molecular biophysics and machine learning to study protein regulation, allosteric signaling, and structure-based drug design.

## Research

- Molecular dynamics
- Machine learning
- Structural bioinformatics
- Mathematical modeling
